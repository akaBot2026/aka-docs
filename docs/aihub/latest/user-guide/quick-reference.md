# Quick Reference

## Navigation & roles

| Goal | Navigation | Minimum typical role |
|---|---|---|
| Ask an assigned Channel | **Chat** | Business user |
| Review citation | **Chat → Sources** | Business user with source access |
| Upload a document | **Knowledge → Documents** | Knowledge editor |
| Manage knowledge access | **Knowledge → Access & sharing** | Knowledge access manager |
| Build/test a Channel | **Channels → Draft/Test** | Channel builder |
| Publish a Channel | **Channels → Publish** | Channel publisher |
| Configure a provider/model | **Management → Connections** | Platform administrator |
| Set policies/limits | **Management → Limits & Data** | Platform administrator |
| Check effective access | **Management → Directory & Access Audit** | Access administrator / Platform admin |
| Inspect a run | **Management → Run history → AI activity** | Operations reader / Platform admin |
| Review configuration changes | **Management → Run history → System logs** | Audit reader / Platform admin |
| Suspend a principal/organization | **Management → Run history → Protective cut-offs** | Emergency operator / Platform admin |

For the full permission model, see [Getting Started: Roles and permissions](./getting-started.md#step-3-know-what-youre-allowed-to-do).

## Support information

When contacting support, include the **Support reference** (`correlationId`) displayed on the error screen.
Submit your request through the support channel configured for your organization (for example, your internal helpdesk, JIRA service desk, or the contact provided by your Akabot account team).

Use the [Support request template](./troubleshooting.md#support-request-template) to structure your submission.
