# Signature and signing password are configured

Your personal profile has a signature image and signing password, which are required for approval steps that require a signature.

**Check:** In Personal Profile → the "Signature" tab, confirm that the signature image is visible and the message "Signing password has been set." appears.


This is required only when the request type or approval step has "Require approval signature" enabled. If either item is missing, you cannot approve the request (see [Rules for approving, rejecting, returning, and delegating](../../reference/approvals/action-rules.md)).


## How to fix

- [Set up a signature and signing password in your profile](../../guides/profile/how-to/set-signature.md) — In Personal Profile, open the Signature tab, draw or upload a signature image, and set a signing password to use when signing approvals.

## Used in these guides

- [Approve an assigned task](../../guides/approvals/how-to/approve-task.md) — Open Tasks and click Approve on the row, or open the request and click Approve on the Your Tasks card. For steps that require a signature, sign using your signing password.
- [Set up a signature and signing password in your profile](../../guides/profile/how-to/set-signature.md) — In Personal Profile, open the Signature tab, draw or upload a signature image, and set a signing password to use when signing approvals.
