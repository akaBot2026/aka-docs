# AI Assistant is enabled for your role

An administrator enabled at least one assistant tool used by your role, so the AI Assistant button is now visible.

**Check:** Look for the ✨ "AI Assistant" button at the top of the page (or a floating bubble in the corner of the screen). If it isn't there, the assistant hasn't been enabled for you.


By default, no tools are enabled, so the assistant is hidden from everyone until an administrator enables tools in AI Settings → Assistant → Assistant Tools. Non-admins can't enable tools themselves; ask an administrator.


## How to fix it

- [Enable assistant tools](../../guides/admin/how-to/enable-assistant-tools.md) — In AI Settings, on the Assistant tab, under Assistant Tools, select the assistant tools to use (by group or individually), then click Save.
