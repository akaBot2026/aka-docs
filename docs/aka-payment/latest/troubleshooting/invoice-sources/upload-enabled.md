# User Upload Source Is Enabled

The User Upload invoice source is enabled, so users can upload invoice files to the Invoice Management page.

**Check:** Invoice Management does not show the warning "Upload source is turned off. Turn it back on in Admin › Incoming Invoices" and has a "User Upload" source card with an Upload button. For administrators: in Admin → Incoming Invoices, the "User Upload" card shows "Enabled".


This source is enabled by default. This is an organization-wide setting, not configured separately for each unit. Regular users cannot enable it themselves; an administrator is required.


## How to fix

- [Enable/disable invoice sources and save settings](../../guides/invoice-sources/how-to/configure.md) — In Admin → Incoming Invoices, select the unit scope, enable/disable each source, adjust the format, size, checks on the e-Invoice Portal, and frequency, then click Save changes.

## Used in these guides

- [Enable/disable invoice sources and save settings](../../guides/invoice-sources/how-to/configure.md) — In Admin → Incoming Invoices, select the unit scope, enable/disable each source, adjust the format, size, checks on the e-Invoice Portal, and frequency, then click Save changes.
- [Upload invoice files to Invoice Management](../../guides/invoices/how-to/upload.md) — In Invoice Management, click Upload on the User Upload card, select an XML/PDF/image or ZIP file, then click Upload; the system automatically reads each invoice.
