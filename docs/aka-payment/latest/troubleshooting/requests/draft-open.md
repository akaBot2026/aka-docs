# Opening a draft request

A request is in Draft status in the creation flow and already has a document number.

**Check:** The "Create Payment Request" page displays a document number (for example, TT.19102026.00001) and a "Draft" label in the top-right corner of the Creation Flow bar.


A draft request is created as soon as you open the Create Payment Request page; until you submit it, it remains in Draft status.


## How to fix it

- [Open a new request and complete the Overview step](../../guides/requests/how-to/start-draft.md) — Click Create Payment Request, complete the Overview step, then click Continue to go to Expense Breakdown.

## Used in these guides

- [Select invoices and create a payment request](../../guides/invoices/how-to/create-request.md) — Select the Ready invoices in Invoice Management, click Create Payment Request, select a Request Type, and click Create Payment Request; each invoice becomes an expense item in the draft.
- [Reconcile documents for an expense](../../guides/reconciliation/how-to/check-expense.md) — For a request type with reconciliation enabled, click Reconcile on the expense row (or Bulk Reconcile) and review the results; the system also reconciles automatically at certain times.
- [Add an expense from an invoice](../../guides/requests/how-to/add-invoice-expense.md) — In the Expense Breakdown step, select Add from Invoice, upload an invoice or select one from the Invoice Management list; each invoice becomes an expense row.
- [Attach shared documents to a request](../../guides/requests/how-to/add-shared-documents.md) — In the Expense Breakdown step, click Shared Documents and attach documents that apply to all expense rows.
- [Apply allocations to all expenses](../../guides/requests/how-to/apply-expense-defaults.md) — In the Expense Breakdown step, open Apply to All Expenses, select an expense item, department (and project), then click Apply.
- [Check the budget before submitting](../../guides/requests/how-to/check-budget.md) — In the Expense Breakdown step, select Check Budget to see whether expenses exceed the allocation.
- [Import a document bundle as expense rows](../../guides/requests/how-to/import-bundle.md) — In the Expense Breakdown step, select Import Document Bundle and upload multiple files, a PDF, or a zip file; the system splits them into expense rows.
- [Open a new request and complete the Overview step](../../guides/requests/how-to/start-draft.md) — Click Create Payment Request, complete the Overview step, then click Continue to go to Expense Breakdown.
