# Who can view a request

Administrators, operators, creators, assignees, approvers, watchers, people in the relevant organizational-unit tree, and people the request is shared with can view it; others cannot.

**Requirement level:** Required


Viewing rules: administrators or operators; the creator; anyone currently or previously assigned to an approval step, or a watcher; anyone whose organizational unit is in the request's approval or cost-bearing unit tree (not applicable to drafts); and anyone the request is shared with. Others cannot open the request (403 error).
