# Start a New Request and Complete the Overview Step

Click Create Payment Request, complete the Overview step, then click Continue to go to Expense Breakdown.

## Before you begin

- **[Requirements for continuing through the request creation flow](../../../reference/requests/draft-validation.md)**\
  Each step in the creation flow has required fields. If any are missing, clicking Continue displays "Please fix the highlighted fields."


## Steps

1. Click **Create Payment Request** at the top of the page to open the default request type. Click the arrow next to it to open the list of enabled request types and find and select one (sample data: Payment, Advance, Reimbursement, Prepayment, Other Payment; the actual list is configured by an administrator). A draft is created immediately.

   ![My Requests page header: (1) Create Payment Request button and the request type list opened from the adjacent arrow (Payment, Advance, Reimbursement, Prepayment, Other Payment)](/static/img/aka-payment-latest-requests-start-draft-button.webp)

2. In the **1 Overview** step, enter the **Request Purpose** (2). Check the **Requester** (you), **Approval Unit** (your unit), **Payee** (pre-filled), and other fields, such as Request Date, Document Number, Company, Budget Period, Payment Deadline, and Request Description. The Approval Unit is also the default Cost Center for expense lines.

   ![Step 1 Overview of the draft: (2) Request Purpose field; Requester, Approval Unit, Budget Period, and Payee are pre-filled; (3) Continue button](/static/img/aka-payment-latest-requests-start-draft-overview.webp)

3. Click **Continue** (3) to go to the **2 Expense Breakdown** step.


## Result

- [Opening a draft request](../../../troubleshooting/requests/draft-open.md) — A request is in Draft status in the creation flow and has a document number.
