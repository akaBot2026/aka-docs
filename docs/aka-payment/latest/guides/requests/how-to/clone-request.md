# Clone a Request

In My Requests, click the copy icon (Clone) on a row to create a new draft from an existing request, especially one that was rejected.


## Steps

1. Open **Payment Requests** → **My Requests** and find the request you want to recreate.
2. Click the copy icon at the end of the row (the **Clone** action, available in every status).
3. The system creates a new draft of the same request type and opens it in **Create Workflow**; review it, then continue as described in [Create a request and fill it out through the Review step](create-draft.md).


## Used in these guides

- [Recreate a rejected request](../clone-request.md) — The creator has a rejected request (which can't be edited) and wants to submit it again using the original content.
- [Reject a request](../../approvals/how-to/reject-request.md) — Open the request awaiting your review and click Reject in the Your Tasks card, enter a reason if you want, then click Confirm; this decision is final.
