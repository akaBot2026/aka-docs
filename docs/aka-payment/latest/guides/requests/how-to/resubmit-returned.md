# Edit and Resubmit a Returned Request

Open the returned request, click Edit and Resubmit, make changes based on the reason, then submit the request. Only the returned step is reopened.

## Before you begin

- **[Request submission requirements](../../../reference/requests/submission.md)**\
  You cannot submit if the form is incomplete, an invoice is duplicated, required documents are missing, reconciliation is incomplete, or the budget is exceeded (at the Block level).


## Steps

1. Read the return reason on the request details page (the reason is also included in the returned request notification).
2. Click **Edit and Resubmit** at the top of the details page (the button is visible to the creator only after the request is returned); **Create Workflow** opens directly at step **2 Expense Details**.
3. Add supporting documents, edit expenses or payments based on the reason, and reconcile again if reconciliation applies to the request type.
4. Go to step **4 Review** and click **Submit Request**. Only the returned step is reopened; previously approved steps remain unchanged.

## Troubleshooting

- Submission is blocked: see [Request submission requirements](../../../reference/requests/submission.md).
