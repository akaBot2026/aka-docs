# Attach shared documents to the entire request

At the Expense Details step, click Shared documents and attach files that apply to every expense line.


## Steps

1. At **2 Expense Details**, click **Shared documents** (the dialog says "Attach to all N expense lines and use when reconciling each line").
2. Drag and drop files into the "Unclassified documents" area (for other documents or a file containing multiple documents; during reconciliation, the system automatically assigns each file to the correct document type), or click **Attach** for each document type (for example, "Quotation" or "Payment notification / Notice from supplier"). New files show "Upload on confirmation".
3. If a file is in the wrong section, click the **Change document type** icon on the file and select a section under **Move to** (shows "Save on confirmation"); click **Remove document** to remove the file.
4. Click **Accept** to save, or **Cancel** to discard the changes (no files will be uploaded).

## Troubleshooting

- Invoices cannot be used as shared documents (the server rejects the save). Attach an invoice to each line using **Attach invoice** or [Add an expense from an invoice](add-invoice-expense.md).


## Prerequisites

- [A draft request is open](../../../troubleshooting/requests/draft-open.md) — A request is in Draft status in the creation workflow and already has a document number.
