# Check budget before submitting

In the Expense Report step, select Check budget to see whether expenses exceed the allocation.


## Steps

1. In step **2 Expense Report**, click the arrow next to **Add expense** (on mobile: the ⋯ menu), then select **Check budget**. This option is available only when budget checking is enabled for the request type.
2. Review the "Budget check results" dialog. For each Category and Unit (and Project when the budget is project-based), it shows the Allocation, Used, This request, and Over amount, along with the "Over budget" label.
3. If the request is over budget, expand "N expense lines" below (look for the "Change category for expense line" suggestion to change the category), or leave it as is if you accept the overage.
4. Click **Close**.


## Notes

- **[Budget overrun rules](../../../reference/budget/overrun.md)**\
  For each request type, set Budget check to Off, Warning, or Block. The default is Warning, and the Payment type is currently set to Warning.

## Prerequisites

- [Open a draft request](../../../troubleshooting/requests/draft-open.md) — A request is in Draft status in the creation workflow and has a document number.
