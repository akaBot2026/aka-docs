# Resubmit a Returned Request

The creator has a returned request and wants to make changes before resubmitting it to the approver.

**When to use:** The creator receives a notification that a request has been returned.


Make the changes based on the return reason, then resubmit. Previously approved steps do not need to be approved again.


## Ways to do this

- [Edit and resubmit a returned request](how-to/resubmit-returned.md) — Open the returned request, click Edit and Resubmit, make changes based on the return reason, then submit the request. Only the returned step is reopened.

## Before you start

- **[Request submission requirements](../../reference/requests/submission.md)**\
  You cannot submit the request if the form is incomplete, an invoice is duplicated, required supporting documents are missing, reconciliation is incomplete, or (at the Block level) the budget is exceeded.

## Steps

[Edit and resubmit a returned request](how-to/resubmit-returned.md)

1. [Edit and resubmit a returned request](how-to/resubmit-returned.md)
   1. Read the return reason on the request details page. The reason is also included in the returned request notification.
   2. Click **Edit and Resubmit** at the top of the details page. This button is only shown to the creator when the request has been returned. **Create Workflow** opens directly to step **2 Expense Report**.
   3. Add supporting documents or update the expenses or payment details based on the return reason. Reconcile again if the request type requires reconciliation.
   4. Go to step **4 Review** and click **Submit Request**. Only the returned step is reopened; previously approved steps remain unchanged.
