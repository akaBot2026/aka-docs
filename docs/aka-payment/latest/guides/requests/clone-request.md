# Re-create a rejected request

The requester has a rejected request that they cannot edit and wants to recreate it using the original content.

**When to use:**

- A request was rejected, and the requester wants to create a new one with the same details.
- The requester wants to start a new request based on an existing one.


Clone the request into a new draft instead of entering everything from scratch.


## Ways to do this

- [Clone a request](how-to/clone-request.md) — In My Requests, click the copy icon (Clone) on the row to open a new draft based on the existing request, especially if it was rejected.

## Steps

[Clone a request](how-to/clone-request.md)

1. [Clone a request](how-to/clone-request.md)
   1. Open **Payment Requests** → **My Requests** and find the request you want to recreate.
   2. Click the copy icon at the end of the row (the **Clone** action, available in all statuses).
   3. The system creates a new draft of the same request type and opens it in **Creation Flow**; review it and continue as described in [Create a request and complete it through the Review step](how-to/create-draft.md).
