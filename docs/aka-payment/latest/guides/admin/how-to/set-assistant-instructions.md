# Write custom instructions for the assistant

In AI Settings, open the Assistant tab, expand Assistant Instructions, enter your organization’s notes (up to 4,000 characters), then click Save.


## Steps

1. In the sidebar, under **Administration**, open **AI Settings** (administrators only, on desktop), then select the **Assistant** tab.
2. Expand **Assistant Instructions** (collapsed by default).
3. Enter your organization’s notes, such as preferred names, tone, or policies to mention (for example: Call the accounting department “Finance.” Respond formally.). The counter below shows the character count, up to 4,000. If you exceed the limit, the counter turns red and the **Save** button is disabled.
4. Click **Save**. These notes come after the assistant’s fixed rules and cannot override them (for example, the assistant will still ask for confirmation before making any data changes).


## Use these instructions when

- [Tell the assistant how to address people and follow company policies](../set-assistant-instructions.md) — Administrators want to add organization-specific notes so the assistant uses the right names and tone and mentions relevant policies.
