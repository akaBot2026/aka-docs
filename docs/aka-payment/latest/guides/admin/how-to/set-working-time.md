# Set Working Hours and Holidays

In Working Time, select the working days and hours for the week, add holidays or make-up workdays to the calendar, then click Save.


## Steps

1. In the sidebar, under **Administration**, open **Working Time** (1) (administrators only).

   ![Working Time page: (1) Working Time in the sidebar, (2) Weekly Working Hours tab with Monday through Friday selected as working days, time slots of 08:00–12:00 and 13:00–17:00, the Add Time Slot button, and the weekly grid; Save button in the upper-right corner](/static/img/aka-payment-latest-admin-set-working-time.webp)

2. On the **Weekly Working Hours** tab (2): under **Working Days**, select days from Monday through Sunday; under **Working Hours**, edit the shared time slots (08:00–12:00 and 13:00–17:00 by default), and click **Add Time Slot** (2) if needed.
3. To set custom hours for a day, use the weekly grid below: drag across an empty area to add a time slot, drag a block to move it, drag its edge to change its duration, or click the block to edit **From**/**To** or **Delete Time Slot**, then click **Done**.
4. On the **Holidays and Make-up Workdays** tab: in the calendar (view by **Year** or **Month**), click **Add Day** or drag to select days; enter the **Name**, **Date**, and **Type** (Holiday or Make-up Workday), then click **Apply**. Click an existing day to edit or delete it.
5. Click **Save** (in the upper-right corner). Changes apply only to processing deadlines calculated after saving; previously calculated deadlines remain unchanged.

## Troubleshooting

- **Save** is disabled: read the red message at the top of the page ("At least one day of the week must have working hours." or a time slot ends before it starts, time slots overlap, or a day is missing a name); the tab with the error is marked "This tab has an error".
