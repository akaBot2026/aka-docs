# Tell the assistant how to address people and follow company policies

An administrator wants to add organization-specific notes so the assistant uses the right names and tone and reminds users about policies.

**When to use:**

- The assistant uses the wrong department name or doesn't respond in the company's tone.
- An administrator wants the assistant to remind users about a company policy.
- An administrator wants the assistant to respond formally and use the company's internal names correctly.


Notes are added after the assistant's fixed rules; they can't bypass confirmation steps or safety rules.


## Ways to do this

- [Write custom instructions for the assistant](how-to/set-assistant-instructions.md) — In AI Settings, on the Assistant tab, open Assistant instructions, write the organization's notes (up to 4000 characters), then click Save.

## Steps

[Write custom instructions for the assistant](how-to/set-assistant-instructions.md)

1. [Write custom instructions for the assistant](how-to/set-assistant-instructions.md)
   1. In the sidebar, under **Administration**, open **AI Settings** (administrators only, on desktop) and select the **Assistant** tab.
   2. Open **Assistant instructions** (collapsed by default).
   3. Write the organization's notes: names to use, tone, and policies to mention (for example: Call the accounting department "Finance." Respond formally.). The counter below shows the character count, up to 4000; if you exceed the limit, the counter turns red and the **Save** button is disabled.
   4. Click **Save**. The notes come after the assistant's fixed rules and can't change them (for example, the assistant will still ask for confirmation before any data changes).
