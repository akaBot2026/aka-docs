# Follow a request

Open a submitted request and click Follow (which changes to Unfollow); find it later under Payment Requests → Following.


## Steps

1. Open the details page for a submitted request (draft requests cannot be followed).
2. Click **Follow** in the upper-right corner (next to **Share**); the button changes to **Unfollow** when you’re following the request.
3. View the list under **Payment Requests** → **Following** (the "Following" page, **Following** tab; filter by time, type, and status).
