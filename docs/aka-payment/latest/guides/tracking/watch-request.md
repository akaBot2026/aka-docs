# Watch someone else's request

Users want to receive updates and quickly find a request that isn't theirs.

**When to use:**

- Users want to track the progress of a request they didn't create.
- Users want to receive updates about a request.


Add the request to the Watching list.


## How to do it

- [Watch a request](how-to/watch-request.md) — Open a submitted request and click Watch (the button changes to Unwatch); find it later under Payment Requests → Watching.

## Steps

[Watch a request](how-to/watch-request.md)

1. [Watch a request](how-to/watch-request.md)
   1. Open the details page for a submitted request (draft requests can't be watched).
   2. Click **Watch** in the upper-right corner (next to **Share**); the button changes to **Unwatch** when you're watching the request.
   3. View the list under **Payment Requests** → **Watching** (the "Watch" page, **Watching** tab, with filters for time, type, and status).
