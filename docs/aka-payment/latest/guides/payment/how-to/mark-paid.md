# Record as Paid

An operator or admin opens an approved request and clicks Mark Paid; this action cannot be undone.


## Steps

1. Open the details page for the approved request.
2. On the **Payment** card, click **Mark Paid**; the card says "Record the payment as paid. This action cannot be undone."
3. The request changes to the **Paid** status.

## Troubleshooting

- The card is shown only to the **Operator** and **Admin** roles, and only for approved requests. If an error occurs, the message "Could not record the payment as paid. Please try again." is displayed.
