# Mark a Request as Paid

An accountant wants to mark an approved request as paid.

**When to use:**

- The accountant has transferred the money and wants to update the request.
- The accountant wants to close an approved request as paid.


This is the final step in the request lifecycle, after approval.


## Ways to do this

- [Mark as paid](how-to/mark-paid.md) — An operator or administrator opens an approved request and clicks Paid; this action cannot be undone.

## Steps

[Mark as paid](how-to/mark-paid.md)

1. [Mark as paid](how-to/mark-paid.md)
   1. Open the details page for the approved request.
   2. On the **Payment** card, click **Paid**; the card says "Record that the money has been paid. This cannot be undone."
   3. The request changes to **Paid**.

## Troubleshooting

### [Mark as paid](how-to/mark-paid.md)

- The card is visible only to the **Operations** and **Admin** roles and only for approved requests. If an error occurs, the message "Unable to record the payment. Please try again." is displayed.
