# Choose which notifications to receive

In Personal Profile, on the Notifications tab, turn each notification type on or off; changes are saved immediately.


## Steps

1. Click the user card at the bottom of the sidebar → **Personal Profile**.
2. Select the **Notifications** tab (all notifications are enabled by default).
3. Turn each item on or off, for example, "My request is approved," "A request needs my approval," "A request assigned to me is due soon," "Someone mentions me in a comment," and "An approver adjusts the budget allocation for my request." Each toggle is saved immediately and applies to both in-app and email notifications.
