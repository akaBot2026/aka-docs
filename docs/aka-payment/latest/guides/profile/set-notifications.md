# Change the notifications I receive

Users want to turn off some types of notifications or turn on others.

**When to use:**

- Users receive too many notifications.
- Users want to choose which types of notifications to receive.


Customize notification types for requests, approvals, and comments.


## How to

- [Choose which notifications to receive](how-to/set-notifications.md) — In Personal Profile, open the Notifications tab and turn each notification type on or off. Changes are saved immediately.

## Steps

[Choose which notifications to receive](how-to/set-notifications.md)

1. [Choose which notifications to receive](how-to/set-notifications.md)
   1. Click the user card at the bottom of the sidebar → **Personal Profile**.
   2. Select the **Notifications** tab (all notifications are on by default).
   3. Turn each item on or off, such as "My request is approved," "A request needs my approval," "A request I own is due soon," "Someone mentions me in a comment," and "An approver adjusts the budget allocation for my request." Each toggle is saved immediately and applies to both in-app and email notifications.
