# Return a Request for More Information

The approver asks the requester to edit or add information instead of rejecting the request outright.

**When to use:**

- The approver wants to return the request to the requester for edits.
- The approver needs the requester to provide additional supporting documents.


The request is missing information, and the approver wants to return it with a reason.


## How to do it

- [Return the request to the requester](how-to/return-request.md) — Open the request, click Return, enter a reason (required), and click Confirm. The requester can then make changes and resubmit.

## Before you start

- **[Rules for approving, rejecting, returning, and delegating](../../reference/approvals/action-rules.md)**\
  A reason is required when returning a request; you must select another recipient when delegating; a reason is optional when rejecting; approval may require a signature.

## Steps

[Return the request to the requester](how-to/return-request.md)

1. [Return the request to the requester](how-to/return-request.md)
   1. Open **Tasks** → the **Pending** tab, then click the request to open its details page.
   2. In the "Your Task" card, click **Return** (this button is only available on the details page, not in the list's ⋯ menu).
   3. Enter a **Reason** (required; suggested text in the field: "Please attach the signed contract").
   4. Click **Confirm**. The requester can continue with [Edit and resubmit a returned request](../requests/how-to/resubmit-returned.md).

## Troubleshooting

### [Return the request to the requester](how-to/return-request.md)

- The Confirm button is disabled: you haven't entered a reason. See [Rules for approving, rejecting, returning, and delegating](../../reference/approvals/action-rules.md).
