# Excel Continue

RCA.Activities.Excel.ExcelContinue

## **Description**

This activity skips the remaining activities in the current iteration and moves on to the next row. It can only be used inside a **For Each Excel Row** (or any Excel For-Each loop).

![Excel Continue](/static/img/excel-continue.png)

## **Properties**

**Misc**

* **Display Name (String)** - The name of this activity. You can edit the name of the activity to organize and structure your code better.  
  E.g: Excel Continue
* **Public (Checkbox)** - If you check it, the data of this activity will be shown in the log. Be careful, consider data security before using it.
