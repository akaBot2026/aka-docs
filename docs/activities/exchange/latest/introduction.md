# Exchange

The Exchange Activities Pack contains all the activities used for creating automation projects. These activities enable the robots to:

* Move mail to another folder.
* Send or get email on Microsoft Exchange Server.

**IMPORTANT:** All activities in this package connect using **Exchange Web Services (EWS)**. Microsoft is **retiring EWS entirely for Exchange Online/Microsoft 365** — starting **October 2026**, Microsoft begins disabling EWS globally for all organizations, and EWS is **fully disabled by April 2027**. After that, this package cannot connect to any Microsoft 365/Exchange Online mailbox under any configuration. This retirement does **not** affect on-premises Exchange Server, where EWS remains fully supported. See Microsoft's official notice: [Deprecation of Exchange Web Services in Exchange Online](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/deprecation-of-ews-exchange-online).
