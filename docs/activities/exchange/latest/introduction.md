# Exchange

The Exchange Activities Pack contains all the activities used for creating automation projects. These activities enable you to:

* Move mail to another folder.
* Send or get email on Microsoft Exchange Server.

**Note:** All activities in this package connect using **Exchange Web Services (EWS)** with Basic Authentication and are designed primarily for **on-premises Exchange Server**. For Microsoft 365 or Exchange Online mailboxes, use the **Office 365** activity package instead.
