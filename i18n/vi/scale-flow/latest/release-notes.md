# Scale Flow - Ghi chú phát hành

## v1.0.0 - Mốc tài liệu ban đầu

**Điểm nổi bật**
- Thêm `overview` cho module Scale Flow.
- Xác định phạm vi cốt lõi: thiết lập tài khoản, tích hợp kênh, trả lời tự động bằng AI, quy trình xử lý, sử dụng ticket và quản lý contact.

**Ghi chú**
- Trang này sẽ được cập nhật liên tục khi các tính năng Scale Flow phát triển.
