# akaBotエージェントの使用方法

## **はじめに**

akaBot Agent は、Bot akaBot Studio で構築されたプロセス、または akaBot Center からデプロイされたプロセスを実行できるようにする実行エージェントです。

このドキュメントは、akaBot Agent の使用方法をガイドすることを目的としています。

## **akaBot エージェントの使用**

ボットを操作するには、以下のアクションに従う必要があります。

1. 必要に応じて、akaBot Center への接続を開くようにネットワーク設定を構成します。
2. ボット設定を構成し、akaBot Center に接続します。
3. akaBot Center または akaBot Studio からプロセスを取得します。
4. プロセスの実行/停止、入力引数の設定、履歴の確認を行ってプロセスを制御します。

akaBot Agent を開くには、次のことを行う必要があります。  
– システム トレイをクリックすると、非表示のアイコンが表示されます。  
– akaBot アイコンを右クリックします。  
– [akaBot エージェントを表示] を選択します。

![image-20220505174101-1.png](/static/img/d5b6ed_image-20220505174101-1.png)

その後、akaBot Agent プログラムが次のように画面に表示されます。

![image-20221117102945-5.png](/static/img/2d6c9f_image-20221117102945-5.png)

---

## **ネットワーク設定を構成します**

ネットワークで Bot Center にアクセスするためにプロキシが必要な場合は、まず以下の手順を実行して接続を開くようにプロキシ設定を構成する必要があります。

**ステップ 1:** [設定] 画面で ([ワークフローのリスト] 画面の場合は、右上隅にある [設定] ボタンを選択します)。

**ステップ 2:** [ネットワーク] タブを選択し、ネットワーク設定フォームに情報を入力します。

[プロキシなし] または [自動検出] オプションを選択した場合は、手順 3 に進みます。  
手動プロキシ オプションを選択した場合は、プロキシ設定を指定する必要があります。

* プロキシの種類を選択します。
* プロキシサーバーのURLを入力します。
* プロキシポートを入力します。
* プロキシで認証が必要な場合は、[認証が必要] オプションにチェックを入れて、認証するユーザー名とパスワードを入力します。

![image-20221117102229-3.png](/static/img/5d0ea0_image-20221117102229-3.png)

---

## **ボット設定を構成し、ボット センターに接続します**

ボットを akaBot Center に接続するには、まず akaBot Center にボット設定を登録してエージェント キーを取得する必要があります。

エージェント キーを取得したら、以下のアクションを実行して akaBot Center に接続できます。

**ステップ 1:** [設定] 画面 ([ワークフローのリスト] 画面の場合は、右上隅にある [設定] ボタンを選択します)。

**ステップ 2:** [センター] タブを選択し、中央設定フォームに情報を入力します。

* マシン名: 現在のコンピューターのコンピューター名 (自動的に事前入力されます)。
* エージェント キー: Bot Center に登録されているキー。
* センター URL: ボット センター URL。

**ステップ 3:** [接続] をクリックして、akaBot Center への接続を実行します。

接続に成功すると、akaBot Center のステータスが **接続済み (Connected)** に変わります。

![image-20221117102433-4.png](/static/img/fabb7a_image-20221117102433-4.png)

ボットがすでに akaBot Center に接続されている場合は、「切断」ボタンをクリックしていつでも切断できます。

---

## **akaBot Center または akaBot Studio からプロセスを取得します**

akaBot Agent は自動的に更新され、akaBot Center から公開されたすべてのプロセス パッケージを取得します。

akaBot Studio からパッケージを公開する方法については、リンクを参照してください: [How to use akaBot Studio](/docs/studio/latest/user-guide/how-to-use.md)

---

## **プロセスを制御する**

プロセスの場合、以下のアクションを実行することで制御できます。

* パッケージのプル。
* 詳細の表示、引数の設定、および履歴の確認。
* プロセスの開始 (標準または PiP)。
* プロセスの停止。

### **1. パッケージの新しいバージョンをプルする**

パッケージのバージョンをプルするには、「下矢印」記号をクリックする必要があります。akaBot Agent は、パッケージの新しいバージョンをローカル マシンに自動的にダウンロードします。

ダウンロード後、新しいバージョンの変更は次回の実行時に自動的に適用されます。

![image-20221117102945-5.png](/static/img/2d6c9f_image-20221117102945-5.png)

---

### **2. ワークフロー詳細タブ**

任意のワークフロー カードをクリックすると、**3 つのタブ**で構成されるサイド詳細パネルが開きます。

#### **A. 詳細 (Details) タブ**
選択したワークフローに関するメタデータを表示します:
* **名前 (Name)**: 自動化パッケージ名。
* **バージョン (Version)**: インストールされているパッケージのバージョン。
* **最終実行 (Last Run)**: 最新の実行のタイムスタンプ。
* **最終更新 (Last Update)**: パッケージがインストールまたは更新された日付。
* **説明 (Description)**: パッケージの機能説明。
* *注: すべてのテキスト フィールドは選択してコピー (`Ctrl+C`) できます。*

![Workflow Details Tab](/static/img/agent-details-tab.png)

#### **B. 設定 (Configure) タブ (入力引数)**
ユーザーはプロセスを実行する前に入力パラメーター (`InArgument`) をカスタマイズできます:
* **引数の型と入力検証**: String (最大 4,000 文字)、Int32/数値、Boolean、DateTime をサポートします。
* **必須引数 (`Name*`)**:
  * 必須パラメーターには赤いアスタリスク (`*`) が付いています。
  * **デフォルト値なし**: 入力ボックスが開いています。値が指定されるまで、ワークフローは**実行できません**。
  * **デフォルト値あり**: *「デフォルト値を使用 (Use default value)」*と表示されます。**鉛筆アイコン**をクリックして編集するか、**元に戻す (Undo)** をクリックして元に戻します。
* **保存して実行 (Save & Run)**: **保存 (Save)** をクリックして今後の実行のためにカスタム値を保持するか、**実行 (Run)** をクリックして検証し直ちに実行します。

![Workflow Configure Arguments](/static/img/agent-configure-tab.png)

#### **C. 履歴 (History) タブ (タスク履歴)**
過去の実行の監査ログを提供します:
* **実行レコード**: ステータス (成功、失敗、キャンセル)、開始時刻、所要時間。
* **タスク詳細モーダル**: 過去の実行をクリックして、実行ソース (Local、Center、PiP)、出力引数の値、エラー ログを確認できます。

![Workflow Execution History](/static/img/agent-history-tab.png)

### **3. プロセスを開始する**

一度に開始できるプロセスは 1 つだけで、**ユーザーのマシンで実行**と**Picture-in-Picture で実行**の 2 つのモードがあります。

#### **ユーザーのマシンモードでプロセスを実行**

プロセスを開始するには、「再生」記号をクリックします。

「再生」をクリックすると、プロセスの実行が開始され、ボットのステータスが **実行中 / ビジー (Running / Busy)** に変わります。

![image-20221117103154-6.png](/static/img/119849_image-20221117103154-6.png)

#### **Picture-in-Picture (PiP) モードでプロセスを実行**

Picture-in-Picture を使用すると、マシン上の現在の作業を中断することなく、有人オートメーションを実行できます。ロボットが PiP で動作している間、メイン画面は自由に使用できます。

PiP モードでプロセスを開始するには、ワークフロー カード上の PiP アイコンをクリックします。

![image-20221117135605-8.png](/static/img/d21165_image-20221117135605-8.png)

PiP モードで初めて実行する場合、ボットがセカンダリ デスクトップ セッションを初期化するために、ユーザーは Windows の資格情報を指定する必要があります。

![image-20221117140949-9.png](/static/img/b6ccf9_image-20221117140949-9.png)

「PiP で実行」を選択すると、フローティング セッションが開きます。**「制御を取得 (Take control)」**を切り替えてマウスやキーボードで操作したり、**「最上部に維持 (Keep on top)」**を切り替えて実行を監視したりできます。

![328420978_738762340828688_4227970519572779063_n.png](/static/img/e9d235_328420978_738762340828688_4227970519572779063_n.png)

---

### **4. プロセスを停止する**

プロセスの実行中に、「停止」ボタンをクリックして手動で停止できます。  
停止後、ロボットのステータスは **Available (利用可能)** に戻り、関連するプロセスは終了します。

![image-20221117103353-7.png](/static/img/1cd410_image-20221117103353-7.png)
