# ST-MRD-009 - 深くネストされたアクティビティ

**ルール ID：** ST-MRD-009

**スコープ：** ワークフロー

## 説明

このルールは、ワークフローに互いの中に配置されたアクティビティが多すぎるかどうかをチェックします（例：別の*シーケンス*内の*ループ*内の*If*）。深いネストにより、オートメーション ロジックの読み取り、テスト、保守が非常に複雑になります。デフォルトでは、ネストの深さが 7 レベルに達した場合にアナライザーが警告します。

![st-mrd-009](/static/img/st-mrd-009.png)

## 推奨事項

複雑なロジックを小さな独立したワークフローに分割することで、ネストの深さを減らしてください。これらの小さな部分を呼び出すために**ワークフロー ファイルの呼び出し**アクティビティを使用すると、メイン ワークフローを整理して分かりやすい状態に保てます。

## パラメータ

*   **Threshold：** 許可されるネストされたアクティビティの最大数。デフォルト値：`7`。

これは、ワークフロー アナライザーが少なくとも 7 つのネストされたアクティビティを見つけると、エラー リストにメッセージが記録されることを意味します。しきい値を変更することもでき（例：3 に）、その場合ネストされたアクティビティの数が新しいしきい値を超えた場合のみ、ルールはエラー メッセージを記録します。

### デフォルト値にリセット

デフォルト値にリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。
