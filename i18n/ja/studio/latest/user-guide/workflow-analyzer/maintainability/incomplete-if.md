# ST-MRD-017 - 不完全な If

**ルール ID：** ST-MRD-017

**スコープ：** アクティビティ

## 説明

このルールは、`Then` ブランチと `Else` ブランチの*両方*が完全に空になっている**If** アクティビティを検出します。`If` アクティビティは論理条件（例：`isSuccess = True`）を評価します。ただし、`Then` と `Else` の両方のブランチが空の場合、ボットは条件を評価しますが、その結果に対して何も行いません。これは「デッド コード」とみなされます。処理時間を無駄にし、ワークフローを読む将来の開発者に混乱を引き起こし、通常は開発者がビジネス ロジックの実装を完了し忘れたことを示しています。

![st-mrd-017](/static/img/st-mrd-017.png)

## 推奨事項

この問題を解決してコード品質を向上させるには：

1. **If アクティビティを削除：** 条件チェックがビジネス プロセスに関係なくなった場合は、`If` アクティビティ全体を削除してください。
2. **ロジックを完成：** 条件が必要な場合は、`Then`（条件が満たされる場合）または `Else`（条件が満たされない場合）ブランチに適切なアクティビティをドラッグ アンド ドロップしてください。
3. **コメントを使用：** 将来の開発のためにブランチを意図的に空にしていた場合は、その理由を他の開発者に説明するために `コメント` アクティビティをブランチ内に配置してください。
