# ST-MRD-008 - 空のシーケンス

**ルール ID：** ST-MRD-008

**スコープ：** アクティビティ

## 説明

このルールは、オートメーション プロジェクトをスキャンして、内部に子アクティビティが含まれていない（つまり完全に空の）**Sequence** アクティビティを検出します。空のシーケンスは通常、開発プロセス中に作成された「残骸」です。開発者がプレースホルダーとしてシーケンスをドラッグ インしたが、ロジックの実装を忘れた場合や、シーケンスの内容を削除したがコンテナ自体を削除し忘れた場合によく発生します。空のシーケンスをワークフローに残すと、`.xaml` ファイルのサイズが大きくなり、akaBot Studio のビジュアル インターフェースが乱雑になり、他のチーム メンバーがオートメーションを読んで保守することが困難になります。

![st-mrd-008](/static/img/st-mrd-008.png)

## 推奨事項

アナライザーがこのルールにフラグを立てた場合は、ワークフローをクリーンアップする必要があります：

1. **デッド コードを削除：** 空のシーケンスが不要になった場合は、クリックして `Delete` を押すだけです。
2. **ロジックを実装：** シーケンスが将来のロジックのプレースホルダーとして使用されていた場合は、必要なアクティビティを追加してください（または、現在空になっている理由を説明するために少なくとも `ログ メッセージ` または `コメント` アクティビティを追加してください）。
