# ST-MRD-002 - アクティビティ名

**ルール ID：** ST-MRD-002

**スコープ：** アクティビティ

## 説明

このルールは、ワークフローでまだアクティビティのデフォルトの汎用名（「クリック」、「入力」、「シーケンス」など）が使用されているかどうかをチェックします。デフォルト名に依存すると、特に他の RPA 開発者にとって、ワークフローの読み取り、レビュー、保守が困難になります。

![st-mrd-002](/static/img/st-mrd-002.png)

## 推奨事項

アクティビティの名前をビジネス プロセスで正確に何をするかを説明する名前に変更してください（例：「クリック」を「ログイン ボタンをクリック」に、「入力」を「ユーザー名を入力」に変更するなど）。これにより可読性が大幅に向上し、トラブルシューティングがはるかに容易になります。
