# 設計ベスト プラクティス ルール

このセクションには、akaBot Studio プロジェクトが設計ベスト プラクティスに従っているかどうかをチェックするルールが含まれています。これらのプラクティスに従うことで、オートメーション ワークフローの保守性、可読性、および信頼性が向上します。

ワークフロー アナライザーで利用可能な設計ベスト プラクティス ルールは以下のとおりです：

| ルール名 | ルール ID | スコープ |
| --------- | ------- | ----- |
| [引数数の多さ](./high-arguments-count.md) | ST-DBP-002 | ワークフロー |
| [空の Catch ブロック](./empty-catch-block.md) | ST-DBP-003 | アクティビティ |
| [フローチャートのネスト](./flowchart-nesting.md) | ST-DBP-007 | ワークフロー |
| [空のワークフロー](./empty-workflow.md) | ST-DBP-023 | ワークフロー |
| [遅延アクティビティの使用](./delay-activity-usage.md) | ST-DBP-026 | ワークフロー |
