# ST-DBP-023 - 空のワークフロー

**ルール ID：** ST-DBP-023

**スコープ：** ワークフロー

## 説明

このルールは、実行アクティビティが含まれていないワークフロー ファイルを検出します。これは開発が未完了であるか、ファイルが冗長であることを示している可能性があります。

## 推奨事項

ワークフローにオートメーション ロジックを実装するか、不要になったファイルを削除してください。
