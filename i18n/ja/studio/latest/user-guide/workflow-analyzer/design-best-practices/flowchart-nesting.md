# ST-DBP-007 - フローチャートのネスト

**ルール ID：** ST-DBP-007

**スコープ：** ワークフロー

## 説明

このルールは、保守性と可読性のために、フローチャートがトップ レイヤーとして使用されているかどうかをチェックします。

## 推奨事項

保守性と可読性を確保するために、フローチャートのレイヤー数を最小限に抑えることをお勧めします。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択します。

![st-dbp-007](/static/img/st-dbp-007.png)

デフォルトの MaxLayers カウント値は 1 です。つまり、ワークフロー アナライザーが少なくとも 2 つのフローチャートを見つけた場合、解析結果にメッセージが記録されます。

値を 3 に変更すると、フローチャートの数がしきい値（この場合は 3）を超えた場合のみ、ルールはエラー メッセージを記録します。

## デフォルト値にリセット

ST-DBP-007 のデフォルト値は 1 です。

デフォルト値にリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。

![st-dbp-007](/static/img/st-dbp-007-reset.png)
