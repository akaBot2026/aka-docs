# ST-USG-027 - 必須パッケージ

**ルール ID：** ST-USG-027

**スコープ：** プロジェクト

## 説明

プロジェクトに必須パッケージ（例：ログや セキュリティ フレームワーク）が含まれていることを確認することで、組織の標準を維持します。

![st-usg-027](/static/img/st-usg-027.png)

## 推奨事項

組織のポリシーに準拠するために、パッケージ マネージャーを通じて必要なパッケージをインストールしてください。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択します。好みに応じて **RequiredPackages** パラメータを変更できます。

デフォルトでは、このルールはいかなるアクティビティ パッケージも要求しません。パッケージのフルネームと等号（`=`）で区切ったバージョンを記述してパッケージを追加します（例：`RCA.Excel.Activities=2.5.3`）。

* 以上（`>`）記号を追加して、指定されたバージョンより高いバージョンを要求します。例えば、`RCA.Excel.Activities>=2.5.3` はバージョン 2.5.3 以上の RCA.Excel.Activities パッケージを要求します。以上（`>`）記号は等号（`=`）と組み合わせてのみ使用できます。`RCA.Excel.Activities>2.5.3` のような入力は無効です。
* 未満（`<`）および以下（`<=`）記号はサポートされていないため、`RCA.Excel.Activities<2.5.3` または `RCA.Excel.Activities<=2.5.3` のような入力は無効とみなされます。
* ワイルドカード文字 `*` を使用して、同じパッケージの複数のバージョンのいずれかを要求します。例えば、`RCA.Excel.Activities=2.7.2-beta*` の値は、RCA.Excel.Activities パッケージの任意の 2.7.2-beta バージョンを要求し、以下のバージョンが含まれている場合はルールがエラーを生成します：
  * `RCA.Excel.Activities=2.7.2`
  * `RCA.Excel.Activities=2.7.2` パッケージの他のプレリリース バージョン（alpha バージョンなど）
  * `RCA.Excel.Activities` パッケージの他の安定版およびプレリリース バージョン
* ワイルドカード文字 `*` はバージョンの末尾にのみ使用できます。また、以上（`>=`）記号をワイルドカード文字 `*` と一緒に使用すると、以上記号（`>=`）は等号（`=`）として解釈されます。

**例：**
* `RCA.Excel.Activities=2.8.4-*`
* `RCA.Excel.Activities>=2.7.2`
* `RCA.Excel.Activities=2.7.2`

複数のパッケージを要求するには、カンマで区切ります。例えば、`RCA.Excel.Activities, RCA.UIAutomation.Activities` は、RCA.Excel.Activities と RCA.UIAutomation.Activities の任意のバージョンをプロジェクトに追加することを要求します。

**注意：** アクティビティが属するパッケージを確認するには、「アクティビティ」パネルで「パッケージでグループ化」オプションを使用します。簡単に確認する別の方法として、パネル内のアクティビティにマウスを重ねてツールチップを読む方法もあります。

## デフォルトにリセット

デフォルトでは、このルールはいかなるパッケージも要求しません。ルールをデフォルトにリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。デフォルト アクションもデフォルト値にリセットされます。
