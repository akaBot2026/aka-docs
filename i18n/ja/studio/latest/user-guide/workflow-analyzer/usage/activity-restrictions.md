# ST-USG-026 - アクティビティ制限

**ルール ID：** ST-USG-026

**スコープ：** アクティビティ

## 説明

このルールは、プロジェクト内で制限されたアクティビティが使用されていないかどうかをチェックします。制限されたアクティビティは、禁止アクティビティまたは許可アクティビティのリストで定義されます。

* **禁止アクティビティ** - プロジェクトで許可されていないアクティビティ。このリストにないすべてのアクティビティはプロジェクトで使用できます。
* **許可アクティビティ** - プロジェクトで許可されているアクティビティ。このリストにあるアクティビティのみがプロジェクトで使用できます。

![st-usg-026](/static/img/st-usg-026.png)

## 推奨事項

アクティビティが組織のポリシーで許可されていることを確認するか、承認された代替手段に置き換えてください。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択し、**ProhibitedActivities** リストまたは **AllowedActivities** リストを使用して制限されたアクティビティを定義します。ルールを変更する場合：

* アクティビティの名前空間（例：`RCA.Activities.Common`）をカンマ（`,`）で区切って追加します。
* 各エントリの先頭または末尾にアスタリスク（`*`）ワイルドカード文字を使用できます。例えば、`RCA.Activities.Common.*` を禁止アクティビティのリストに追加すると、`RCA.Activities.Common` で始まる名前空間を持つアクティビティは許可されません。
* **重要：** リストを同時に使用しないでください。両方のリストに値が入力されている場合、禁止アクティビティのリストが優先されます。

## デフォルトにリセット

デフォルトでは、このルールはいかなるアクティビティの使用も制限しません。ルールをデフォルトにリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。
