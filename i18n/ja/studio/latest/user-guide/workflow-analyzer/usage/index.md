# 使用ルール

このセクションには、akaBot Studio プロジェクトがすべての依存関係とアクティビティが適切に活用されていることを確認するなど、使用のベスト プラクティスに従っているかどうかをチェックするルールが含まれています。

ワークフロー アナライザーで利用可能な使用ルールは以下のとおりです：

| ルール名 | ルール ID | スコープ |
| --------- | ------- | ----- |
| [未使用の依存関係](./unused-dependencies.md) | ST-USG-010 | プロジェクト |
| [パッケージ制限](./package-restrictions.md) | ST-USG-014 | プロジェクト |
| [必須パッケージ](./required-packages.md) | ST-USG-027 | プロジェクト |
| [アクティビティ制限](./activity-restrictions.md) | ST-USG-026 | アクティビティ |
| [ログ メッセージの最小数](./minimum-log-messages.md) | ST-USG-020 | ワークフロー |
