# ST-USG-020 - ログ メッセージの最小数

**ルール ID：** ST-USG-020

**スコープ：** ワークフロー

## 説明

ワークフローに、トレーサビリティを向上させるために最低限の数のログ メッセージ アクティビティが含まれていることを確認します。

![st-usg-020](/static/img/st-usg-020.png)

## 推奨事項

実行フローを追跡するために、特に開始、終了、および重要な判断ポイントに、より多くのログ メッセージ アクティビティを追加してください。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択します。好みに応じて **MinLogs** パラメータを変更できます。

## デフォルト値にリセット

ST-USG-020 MinLogs のデフォルト値は `2` です。

デフォルト値にリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。

![st-usg-020-rtd](/static/img/st-usg-020-rtd.png)
