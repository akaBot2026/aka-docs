# ST-USG-014 - パッケージ制限

**ルール ID：** ST-USG-014

**スコープ：** プロジェクト

## 説明

アナライザー設定で設定された制限または廃止されたパッケージの使用を検出します。

![st-usg-014](/static/img/st-usg-014.png)

## 推奨事項

組織のポリシーに従って制限されたパッケージを削除するかアップグレードしてください。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択します。好みに応じて **RestrictedPackage** パラメータを変更できます。

デフォルトでは、このルールはいかなるアクティビティ パッケージの使用も制限しません。制限されたパッケージを定義するには、**RestrictedPackage** パラメータにパッケージを追加します。

* パッケージのフルネームと等号（`=`）で区切ったバージョンを記述してパッケージを追加します（例：`RCA.Excel.Activities=2.5.3`）。
* 以上（`>=`）記号を追加して上位バージョンを制限します。例えば、`RCA.Excel.Activities>=2.5.3` を制限されたパッケージ パラメータに追加すると、バージョン 2.5.3 以上のすべての 'RCA.Excel.Activities' パッケージが禁止されます。以上（`>`）記号は等号（`=`）と組み合わせてのみ使用できます。`RCA.Excel.Activities>2.5.3` のような入力は無効です。
* 未満（`<`）および以下（`<=`）記号はサポートされていないため、`RCA.Excel.Activities<2.5.3` または `RCA.Excel.Activities<=2.5.3` のような入力は無効とみなされます。
* ワイルドカード文字 `*` を使用して任意の数の文字に一致させることができます。例えば：
  * `RCA.Excel.Activities=2.7.2-beta*` を追加すると、RCA.Excel.Activities パッケージのすべての beta バージョン 2.7.2-beta が制限され、同じパッケージの他のバージョンの使用は許可されます。
  * `RCA.*` をパラメータに追加すると、RCA が公開したすべてのパッケージが制限されます。
  * 以上（`>=`）記号をワイルドカード文字 `*` と一緒に使用すると、以上記号（`>=`）は等号（`=`）として解釈されます。

**例：**
* `RCA.Excel.Activities=2.8.4-*`
* `RCA.Excel.Activities>=2.7.2`
* `RCA.Excel.Activities=2.7.2`

複数の制限されたパッケージを追加するには、カンマで区切ります。例えば、`RCA.Excel.Activities, RCA.UIAutomation.Activities` を追加すると、これら 2 つのパッケージのすべてのバージョンが制限されます。

**注意：** アクティビティが属するパッケージを確認するには、「アクティビティ」パネルで「パッケージでグループ化」オプションを使用します。簡単に確認する別の方法として、パネル内のアクティビティにマウスを重ねてツールチップを読む方法もあります。

## デフォルトにリセット

デフォルトでは、このルールはいかなるパッケージも制限しません。ただし、追加したパッケージをすばやく削除したい場合は、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。デフォルト アクションもデフォルト値のエラーにリセットされます。
