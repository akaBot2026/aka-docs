# セキュリティ ルール

このセクションには、akaBot Studio プロジェクトが機密データの正しい取り扱いなど、セキュリティのベスト プラクティスに従っているかどうかをチェックするルールが含まれています。

ワークフロー アナライザーで利用可能なセキュリティ ルールは以下のとおりです：

| ルール名 | ルール ID | スコープ |
| --------- | ------- | ----- |
| [機密引数の SecureString](./securestring-for-sensitive-arguments.md) | ST-SEC-007 | ワークフロー |
| [機密変数の SecureString](./securestring-for-sensitive-variables.md) | ST-SEC-008 | アクティビティ |
