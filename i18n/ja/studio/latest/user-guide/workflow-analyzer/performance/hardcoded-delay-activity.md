# ST-PRR-004 - ハードコードされた遅延

**ルール ID：** ST-PRR-004

**スコープ：** アクティビティ

## 説明

このルールは、**遅延**アクティビティが変数や設定から値を読み取るのではなく、固定で手動入力した時間（ハードコードされたリテラル、例：`"00:00:05"`）を使用しているかどうかをチェックします。

ワークフロー内に固定の時間値を直接使用すると、後で遅延を調整することが困難になります。例えば、テスト環境と本番環境で異なる遅延時間が必要な場合、変更するためにワークフローを手動で開いて編集しなければなりません。

![st-prr-004](/static/img/st-prr-004.png)

## 推奨事項

時間をそのまま遅延アクティビティに入力する代わりに、期間を**変数**、**引数**、または外部の**設定ファイル**に保存することを強くお勧めします。

この変数を遅延アクティビティに渡すことで、基盤となるワークフロー コードを変更することなく、将来的に待機時間を簡単に管理・更新できます。
