# ST-ANA-006 - メイン ワークフローの存在

**ルール ID：** ST-ANA-006

**スコープ：** プロジェクト

## 説明

このルールは、プロジェクトのルート ディレクトリに `Main.xaml` という名前のファイルが存在するかどうかを確認します。akaBot では、`Main.xaml` ファイルはオートメーションの主要なエントリ ポイント（開始ノード）として機能します。プロジェクトを公開して akaBot Center またはエージェントから実行する場合、システムはこのファイルを使用してどこから実行を開始するかを把握します。`Main.xaml` ファイルがないと、ボットは本番環境で実行できません。

![st-ana-006](/static/img/st-ana-006.png)

## 推奨事項

ワークフロー アナライザーがこのルールにフラグを立てた場合、`Main.xaml` ファイルが見つからない、名前が変更されている、またはルート フォルダーから移動されていることを意味します。これを解決するには：

1. **作成または名前変更：** プロセスの残りを調整する主要なワークフローが既にある場合は、`Main.xaml` に名前変更してプロジェクトのルート フォルダーに配置してください。
2. **メインとして設定：** akaBot Studio の**プロジェクト**パネルで、開始点として使用するワークフロー ファイルを右クリックし、**メインとして設定**を選択します（これにより、プロジェクトのメイン エントリ ポイントとして指定されます）。
