# 命名ルール

このセクションには、akaBot Studio プロジェクト内のアイテムが標準的な命名規則に従っているかどうかをチェックするルールが含まれています。一貫した命名規則に従うことで、変数と引数の目的を把握しやすくなり、オートメーション プロジェクトの保守が容易になります。

ワークフロー アナライザーで利用可能な命名ルールは以下のとおりです：

| ルール名 | ルール ID | スコープ |
| --------- | ------- | ----- |
| [変数の命名](./variable-naming.md) | ST-NMG-001 | アクティビティ |
| [引数の命名](./argument-naming.md) | ST-NMG-002 | ワークフロー |
| [親変数のシャドウイング](./parent-variable-shadowing.md) | ST-NMG-003 | ワークフロー |
| [表示名の重複](./display-name-duplication.md) | ST-NMG-004 | ワークフロー |
| [変数のシャドウイング](./parent-variable-shadowing.md) | ST-NMG-003 | ワークフロー |
| [変数と引数の衝突](./variable-argument-collision.md) | ST-NMG-006 | ワークフロー |
| [変数の長さ](./variable-length.md) | ST-NMG-008 | アクティビティ |
| [DataTable 変数のプレフィックス](./prefix-datatable-variables.md) | ST-NMG-009 | アクティビティ |
| [DataTable 引数のプレフィックス](./prefix-datatable-arguments.md) | ST-NMG-011 | ワークフロー |
| [引数の長さ](./argument-length.md) | ST-NMG-016 | ワークフロー |
