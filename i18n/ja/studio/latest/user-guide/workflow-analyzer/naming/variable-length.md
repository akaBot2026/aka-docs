# ST-NMG-008 - 変数の長さ

**ルール ID：** ST-NMG-008

**スコープ：** アクティビティ

## 説明

変数名が説明的でありながら過度に長くならないことを確保し、コードの可読性を維持します。

![st-nmg-08](/static/img/st-nmg-08.png)

## 推奨事項

説明的な意味を保ちながら、変数名をより簡潔に短縮してください。

## ルールの変更

リボンで **解析** ボタンのドロップダウンをクリックし、**解析の設定**を選択してアナライザー ウィンドウを開きます。ルールを見つけて選択します。**MaxLength** フィールドにカスタムの文字数を追加できます。

数値 10 を追加すると、ファイルまたはプロジェクトで定義された変数名が 10 文字を超えているかどうかをルールがチェックします。

## デフォルト値にリセット

ST-NMG-008 MaxLength のデフォルト値は `20` です。

デフォルト値にリセットするには、アナライザー ウィンドウでルールを右クリックし、**デフォルトにリセット**をクリックします。
