# ST-NMG-009 - DataTable 変数のプレフィックス

**ルール ID：** ST-NMG-009

**スコープ：** アクティビティ

## 説明

このルールは、DataTable 型でワークフローに定義された DataTable 変数の名前が `dt_` プレフィックスで始まっているかどうかをチェックします。

![st-nmg-09](/static/img/st-nmg-09.png)

## 推奨事項

既存の DataTable 変数の名前が `dt_` プレフィックスで始まっていることを確認してください。
