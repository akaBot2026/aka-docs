# ST-NMG-011 - DataTable 引数のプレフィックス

**ルール ID：** ST-NMG-011

**スコープ：** ワークフロー

## 説明

このルールは、DataTable 型でワークフローに定義された DataTable 引数の名前が `dt_` プレフィックスで始まっているかどうかをチェックします。

![st-nmg-011](/static/img/st-nmg-011.png)

## 推奨事項

既存の DataTable 引数の名前が引数の型に続いて `dt_` プレフィックスで始まっていることを確認してください。
