# ST-NMG-005 - 変数のシャドウイング

**ルール ID：** ST-NMG-005

**スコープ：** ワークフロー

## 説明

このルールは、特定のアクティビティ（シーケンスやループなど）内に、ワークフロー全体（親スコープ）の別の変数や引数と全く同じ名前の変数を作成していないかどうかをチェックします。これが発生すると、内側の変数が外側の変数を「隠す」または「シャドウする」ことになります。これにより、実行中にオートメーションが誤ったデータを使用するという混乱したエラーが発生する可能性があります。

![st-nmg-05](/static/img/st-nmg-05.png)

## 推奨事項

内側（子）スコープの変数を一意になるように名前変更してください。これにより、ワークフローが正しい変数を使用し、予期しない動作を回避できます。
