# トラブルシューティング

画面に表示されるメッセージや、発生している状況から、該当する問題を探してください。

## よくある問題

| 表示される内容 | 対処方法 |
| --- | --- |
| `Publish this Pipeline before uploading Documents.` | 先にバージョンを公開してください。Draft を保存しただけでは不十分です。[テストと公開](./pipelines/test-and-publish.md)を参照してください |
| 結果に文書タイプが含まれていない | `Document Type Key` が、分類が返すタイプと完全に一致していません。[Pipeline の作成](./pipelines/create-a-pipeline.md)を参照してください |
| Excel ファイルが処理されない | PDF または CSV に変換してください。[対応ファイルと制限](./documents/upload-and-track.md#files-and-limits)を参照してください |
| Document をエクスポートできない | エクスポートできるのは `Confirmed` の Document のみです。Review を開き、`Confirm` を選択してください |
| Review での修正が消えた | 修正は、`Confirm` を選択したときにのみ保存されます。[Review](./documents/review-and-export.md#review) を参照してください |

## サインインとアクセス

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| `Sign-in is not configured` と表示される、またはサインインできない | この環境ではサインインが設定されていない | 発生時刻とアプリケーションのアドレスを添えて、サポートに連絡してください |
| メニューが表示されない、またはアクセスが拒否される | 会社が違う、権限がない、またはメンバーシップが削除された | 会社を確認し、管理者にロールの確認を依頼してください |
| メンバーを追加したが、アクセスできない | ロールが保存されていない | もう一度 `Assign Role` を使用してください。アカウントを作り直さないでください |

## Pipeline

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| `Pipeline name ... already exists` | 同じ名前が別の Pipeline で使われている | 名前を変更するか、既存の Pipeline を開いてください |
| `Select an API Key for the selected AI Model to continue.` | 他のプロバイダーのモデルにキーが設定されていない | Pipeline で、そのプロバイダーのキーを選択してください。`API Keys` で発行したキーはここでは使用できません |
| モデルを利用できない | モデルが削除または無効化された | 利用可能なモデルを選択し、キーを確認して、再度テストしてください |
| ウィザードで先に進めない | 名前またはモデルが未設定、JSON が不正、スキーマのない Classification Prompt、マッピング キーの不足または重複、しきい値または保持期間が不正 | 表示されたステップを修正してください。JSON は有効なオブジェクト、しきい値は 0～100、保持期間は 1～180 日である必要があります |
| Pipeline にすでに Draft がある | Pipeline の Draft は 1 つだけ | バージョン セレクターで、既存の Draft を開いてください |
| `Pipeline draft changed after preflight` | チェック後に設定が変更された | 保存し、再度チェックして、テストしてください |

## Document、Review、Job

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| `File exceeds the configured size limit` と表示される、またはファイル形式に対応していない | ファイルが大きすぎる、または形式が処理対象外 | 対応する形式で、25 MB 未満のファイルを使用してください。Excel は PDF または CSV に変換してください |
| アップロードは成功したが、Job が失敗する | 処理エラーまたはサービス エラー | `Jobs` で `Error Message` を確認し、原因を解消してください。ステータスが許可している場合は再試行してください |
| クォータを超過した、期限切れ、または未設定 | 利用可能なクォータがない | `Quota & Usage` を確認し、管理者に連絡してください |
| 信頼度は高いが、ステータスが `To Review` のまま | 自動承認がオフ、警告がある、またはデータがない | 警告を確認し、結果をレビューしてください。レビューを省略する目的で、しきい値を下げないでください |
| Review で編集または保存できない | 別のレビュー担当者が引き継いだ、またはセッションが中断された | ページを再読み込みし、担当者間で調整してください。確定していない変更は保存されません |
| Job は `Completed` だが、エクスポートできない | Document が `Rejected`、または再度開かれている、あるいは権限がない | Document のステータスを確認してください |
| Retry または Cancel を実行できない | ステータスが変わった、または権限がない | `Jobs` を更新してください。Retry できるのは、`Failed` または `Timed Out` の Job のみです。`Waiting for Review` の Job はキャンセルできません |
| Document が見つからない | フィルター、Pipeline や会社の違い、削除、または保持期間の期限切れ | フィルターを解除し、会社、Pipeline、保持期間を確認してください |

## 連携

| 問題 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| Webhook が `FAILED` または `EXHAUSTED` と表示される | URL、認証、テンプレート、または受信側に問題がある | `Webhook History` で `View` を選択し、受信側のチームと協力して対応してください |
| ScaleConnect が開かない | ブラウザーがポップアップをブロックした | アプリケーションのポップアップを許可し、もう一度 `Connect Service` を選択してください |
| 接続がすでに別の Pipeline にリンクされている | 1 つの接続は、会社内の 1 つの Pipeline にのみリンクできる | 現在のリンクを確認し、管理された手順での接続解除または移行について取り決めてください |
| API キーが機能しない | キーが `Deactive`、期限切れ、失効、または別の Pipeline に限定されている | ステータス、有効期限、対象範囲を確認してください。失効または紛失した場合は、新しいキーを発行してください |

## サポートへの連絡

発生時刻、会社、Pipeline とバージョン、Job ID、ファイル名・形式・サイズ、ステータス、機密情報を取り除いたメッセージを送ってください。承認済みのチャネルを使用する場合を除き、API キー、パスワード、トークン、ヘッダーの値、実際の文書は送らないでください。
