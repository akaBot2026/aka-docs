# フォーカスを設定

RCA.Activities.Common.SetFocus

## **説明**

Set Focus アクティビティは、指定された UI 要素にキーボード フォーカスを設定します。

![Set Focus Activity](/static/img/set-focus-designer.png)

（\*必須）

## **アクティビティ本体内**

* **画面上に表示** - キーボード フォーカスを受け取る UI 要素を選択します。このアクティビティは、その要素の場所を指定するセレクターを生成します。

## **プロパティ**

**共通**

* **エラー時に続行 (ブール値)** - ブール変数には、True または False の 2 つの可能な値があります。
  + **True**: アクティビティ内でエラーが発生した場合でも、プロセスの残りの部分が実行を継続できるようにします。
  + **False**: プロセスの実行の継続をブロックします。
* **Delay After (Int32)** - アクティビティ実行後の遅延時間 (ミリ秒単位)。デフォルトの時間は 300 ミリ秒です。
* **Delay Before (Int32)** - アクティビティが操作の実行を開始するまでの遅延時間 (ミリ秒単位)。デフォルトの時間は 200 ミリ秒です。

**入力**

* **ターゲット (折りたたみ可能なリスト):**
  + **要素 (UIElement)** - 別のアクティビティから返された `UIElement` 変数を使用します。このプロパティは、Selector プロパティと一緒に使用することはできません。
  + **セレクター (文字列)** - アクティビティの実行時に特定の UI 要素を検索するために使用されるテキスト プロパティ。これは実際には、探している GUI 要素とその親の一部の属性を指定する XML フラグメントです。
  + **ファジー セレクター (文字列)** - 類似または動的な属性を持つ UI 要素との一致を可能にします。
  + **TimeoutMS (Int32)** - エラーがスローされるまでにターゲット要素が検出されるのを待機する最大時間 (ミリ秒単位)。デフォルト値: 30000 (ミリ秒)。
  + **準備完了を待つ (ドロップダウン リスト)** - アクションを実行する前に、ターゲットの準備が整うまで待ちます。次のオプションが利用可能です。
    - **なし**: ターゲットの準備が完了するまで待機しません。
    - **インタラクティブ**: アプリケーションの一部が読み込まれるまで待ちます。
    - **完了**: アプリケーション/ページ全体が完全に読み込まれるまで待機します。

**その他**

* **表示名 (文字列)** - デザイナーに表示されるこのアクティビティの名前。アクティビティの名前を編集して、コードをより適切に整理および構造化できます。  
  例: `[8439201] フォーカスを設定`
