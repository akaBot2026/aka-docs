# メールに返信

RCA.Activities.Office365.ReplyToMail

## **説明**

Microsoft Office 365 Outlook で既存のメール メッセージに返信します。(akaBot Studio では "Replay To Mail" と表示されます。)

:::note
このアクティビティは、`Mail` サービスを選択した [Office 365 アプリケーション スコープ](../../office365-application-scope.md) の **Do** ブロック内に配置する必要があります。認証とアクセス許可の設定方法は [Office 365 への接続](../../azure-app-registration.md) を参照してください。
:::

（\*必須）

## **アクティビティ本体**

* なし (プロパティ パネルで設定します)。

## **プロパティ**

**共通**

* **エラー発生時に続行 (ブール値)** - True または False を指定します。
  **- True**: アクティビティ内でエラーが発生しても、プロセスの実行を続行します。
  **- False**: プロセスの実行を停止します。

**入力**

* **アカウント (文字列)** - 返信の送信に使用するメール アカウント。空の場合は、認証されたアカウントが使用されます。
* **メッセージ (Office365Message)**\* - 返信する元の Office365Message オブジェクト。
* **新しい件名 (文字列)** - 返信の新しい件名 (任意)。空の場合は元の件名 (先頭に RE: が付く) が使用されます。

**受信者**

* **宛先を追加 (String[])** - 返信に追加する主な受信者のメール アドレス。
  例: {"colleague@example.com"}
* **CC を追加 (String[])** - 返信に追加する CC 受信者のメール アドレス。
* **BCC を追加 (String[])** - 返信に追加する BCC 受信者のメール アドレス。

**添付ファイル**

* **添付ファイル (`List<String>`)** - 返信に添付するファイル パスの一覧。
* **添付ファイル コレクション (`IEnumerable<String>`)** - 返信に添付するファイル パスのコレクション。

**オプション**

* **本文 (文字列)** - 返信の本文。
  例: "Thank you for the update."
* **重要度 (ドロップダウンリスト)** - 返信の重要度: Low、Normal、High。既定値: Normal。
* **本文が HTML (ブール値)** - 返信の本文が HTML かどうかを指定します。既定値: False。
* **下書き (ブール値)** - True の場合、返信を送信せずに下書きとして保存します。既定値: False。
* **全員に返信 (ブール値)** - True の場合、スレッドの全員 (送信者とすべての CC 受信者) に返信します。False の場合、元の送信者のみに返信します。既定値: False。

**その他**

* **公開 (チェックボックス)** - 選択すると、アクティビティのデータがログに記録されます。使用する前に、データ セキュリティ要件を考慮してください。
* **表示名 (文字列)** - このアクティビティの名前。ワークフローを整理しやすくするために編集できます。
  例: Replay To Mail
