# リリースノート

## v3.4.0.3

ビルド日: 2026年10月26日

- 更新: モダンな範囲アクティビティでは、操作に応じて、単一セル参照をデータブロックの起点または正確な出力先として扱うようになりました。
- 更新: **Append Range** は、出力先が空の場合も含め、指定された出力先範囲の直後に追記するようになりました。
- 修正: **Replace** は、セル値全体を置換するのではなく、最初に部分一致したテキストの前後を保持するようになりました。
- 修正: **Find First/Last Data Row** および **Find/Replace Value** の出力フィールドで変数を使用できるようになりました。
- 修正: 要求されたファイルが存在しない場合、**Use Excel File** と **Excel Application Scope** は新規作成されたブックを開いたまま保持し、初回使用時の RPC エラーを防ぐようになりました。

## v3.4.0.2

ビルド日: 2026年10月15日

- 単一セル範囲を読み取る際に `Add Headers` が有効になっていると、`Excel Read Range` が既定の `Column1` を返し、その値をデータ行として扱う問題を修正しました。

## v3.4.0.1

ビルド日: 2026年10月15日

- 空のセルに書式が設定されているために使用範囲が最終行まで拡張されたワークシートを `Excel Read Range` で処理すると、`OutOfMemoryException` が発生する問題を修正しました。
- 読み取り結果の末尾にある空の行を削除する際のメモリ使用量を削減しました。
- Excel アクティビティの非同期処理完了とエラー伝播を改善し、`AggregateException` ではなく元の例外が報告されるようにしました。

## v3.4.0

ビルド日: 2026年10月15日

**新機能**

- [モダン Excel アクティビティ](./modern/about-modern-excel.md) — シート、範囲、テーブルの参照に対応する **Use Excel File** スコープと、17 個の新しいモダンアクティビティを追加しました。

**詳細**

- `Use Excel File` スコープと、対話的に選択できるワークブック、シート、範囲の参照を備えたモダン Excel エクスペリエンスを追加しました。
- データの読み取り、書き込み、追記、クリア、入力、コピー、フィルター、検索、置換、重複削除を行うモダンアクティビティを追加しました。
- シート名の変更、保護、保護解除、マクロの実行、ワークブックの保存を行うモダンアクティビティを追加しました。
- ローカライズされたアクティビティ名、専用デザイナー、ツールボックスアイコン、対話型の Excel 範囲セレクターを追加しました。
- 入力に単一セルが含まれている場合の `For Each Excel Row` の問題を修正しました。

## v3.3.0

ビルド日: 2026年8月20日

- `Excel Application Scope` 内の範囲の行を反復処理する `For Each Excel Row` アクティビティを追加しました。
- Excel の行ループを制御する専用の `Excel Break` アクティビティと `Excel Continue` アクティビティを追加しました。
- `Excel Application Scope` の `Workbook` ツールチップを更新し、ファイルを開いたままにする動作について説明を追加しました。
- 画像の挿入を含む .NET Framework 4.7.2 との互換性を改善し、パッケージの依存関係を更新しました。

## **アクティビティのインストール方法**

**1. パッケージを手動でダウンロード**

- [こちら](https://ws3.akabot.com/s/GwTK9bPoChHuv8A)をクリックして、アクティビティファイルをダウンロードします。
- `*.nupkg` ファイルを `C:\ProgramData\akaBot\Packages\` に配置します。
- **Studio > Package Manager** で、リストからこのアクティビティを検索してインストールします。

**2. Studio Package Manager を使用**

- **Studio > Package Manager > Settings > User package sources** で、次のリポジトリを追加します: https://gitlab.com/api/v4/projects/75840319/packages/nuget/index.json
- リストからこのアクティビティを検索してインストールします。
