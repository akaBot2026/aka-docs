# リトライ スコープ

RCA.Activities.Core.RetryScope

## **説明**

このアクティビティは、条件が満たされないかエラーがスローされる限り、含まれているアクティビティをリトライします。

![retry-scope.png](/static/img/retry-scope.png)

\* は必須フィールドを示します。

## **プロパティ**

**共通**

* **Continue On Error (ブール値)**: アクティビティがエラーをスローした場合でも実行を継続するかどうかを指定します。サポートされている値: `True`、`False`。

**その他**

* **表示名 (文字列)**: このアクティビティの名前。ワークフローをより適切に整理および構造化するために編集できます。  
  例: `Retry Scope`
* **パブリック (チェックボックス)**: 選択すると、アクティビティ データが記録されます。このプロパティを使用する前に、データのセキュリティを考慮してください。

**入力**

* **リトライ回数 (Int32)**: シーケンスをリトライする回数。デフォルト値は `3` です。
* **リトライ間隔 (TimeSpan)**\*: 各リトライ試行の間に一時停止する時間。デフォルト値は `00:00:05` (5秒) です。
