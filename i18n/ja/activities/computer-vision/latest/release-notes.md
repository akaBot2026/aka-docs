# リリースノート

## **v3.2.0.1**

ビルド日: 2026年9月29日

**修正**

* `project.v1.json` を使用するプロジェクトで、ローカル CV サーバーの検出が失敗する問題を修正しました。
* **CV Type Into** で、**ClickBeforeType** の後に最初の1文字が欠落することがある問題を修正しました。特に Remote Desktop セッションで発生していました。
* **CV Type Into** 使用時に、大文字と小文字が保持されるように修正しました。
* **EmptyField** のクリア処理を `End`、`Left Shift + Home`、`Delete` を使う方式に変更し、Remote Desktop 対象では入力が安定するまでの待機時間を追加しました。
* デザイナーで **EmptyField** を有効にすると、**ClickBeforeType** も自動的に有効になるように更新しました。実行時にも、古いバージョンや手動で編集されたワークフローに対して、クリック要件が強制されるようにしました。

---

## **v3.2.0**

ビルド日: 2026年7月30日

**変更**

* .NET Framework 4.5.2 および 4.7.2 のパッケージ出力を維持しました。
* フレームワークごとの `Newtonsoft.Json` 依存関係を追加しました。 .NET Framework 4.5.2 では 10.0.1、4.7.2 では 13.0.3 です。
* アクティビティ パッケージの脆弱性対応として、`RestSharp` と関連依存関係を更新しました。

---

## **v3.1.0.4**

ビルド日: 2026年1月6日

**変更**

* Computer Vision プロジェクトを SDK スタイルのプロジェクト形式に移行しました。
* .NET Framework 4.5.2 と 4.7.2 の両方に対するパッケージ出力を追加しました。
* パッケージを `3.1.0.4` のリビジョンを保持したまま、3.x 系のバージョンラインへ移動しました。
* プロジェクトとパッケージ参照を簡素化し、アセンブリ メタデータを集約しました。
* ビルド出力に正しい x86 / x64 の OpenCvSharp ネイティブ ライブラリがコピーされるようにしました。
* 新しいランタイムに合わせて JSON 依存関係とバインディング動作を更新しました。

**修正**

* Studio でパッケージが正しく読み込めない可能性があった、競合する日本語リソース ファイルを削除しました。
* アクティビティ プロジェクト内の不要なアプリケーション設定を削除し、冗長な依存関係を整理しました。

---

## **v1.1.0.5**

ビルド日: 2026年1月24日

**変更**

* `Newtonsoft.Json` を 13.0.3 に更新し、サポート対象のパッケージ セットに合わせて `RestSharp` を調整しました。
* NuGet 依存関係を最適化し、未使用の `HtmlAgilityPack` 依存関係を削除しました。

**修正**

* 静的セキュリティ解析の結果に基づき、スクリーンショット、ビットマップ、その他のアンマネージド イメージ リソースの破棄処理を改善しました。
* Computer Vision の選択処理や画像処理ワークフローにおけるリソース リークを削減しました。

---

## **v1.1.0.4**

ビルド日: 2025年7月29日

**追加**

* **CV Screen Scope** と Computer Vision の選択ツールに、クロップ領域の処理を追加しました。
* **CV Element Exists** に追加の言語リソースを追加しました。

**変更**

* **CV Dropdown Select** のテキスト正規化、マッチ順序、およびオプション選択位置を改善しました。
* 重複する要素がある場合のターゲット選択を改善しました。
* メンテナンス互換性向上のため、JSON アセンブリ バインディングを更新しました。

**修正**

* **CV Type Into** の文字の大文字小文字を修正しました。
* **CV Type Into** の入力クリア処理を `Ctrl + A` から `End`、`Shift + Home`、`Delete` に変更しました。
* **EmptyField** が有効なときに **CV Type Into** が対象をクリックするようにしました。
* 再利用可能な入力領域を使用した場合の座標処理を修正しました。
* 繰り返しキャプチャ時に `OutOfMemoryException` が発生する可能性があったビットマップのライフタイム処理を修正しました。

## **v1.1.0.2**

ビルド日: 2024年6月14日

**追加**

* 実行直前に Computer Vision の検出を即時に更新できる **ReDetectScreenScope** を追加しました。
* タイムアウト処理を設定可能にし、ローカライズされたタイムアウト メッセージを追加しました。
* NuGet パッケージにアクティビティ構成ファイルを追加しました。

**変更**

* もっと処理時間が必要なローカルまたはリモートの CV サーバーに対応するため、要求許容値を増やしました。
* **CV Screen Scope** の本文処理をリファクタリングし、古い Studio バージョンで作成されたワークフローとの互換性を維持しました。
* 連携シナリオ向けに `CVScopeOutput` を public にしました。

**修正**

* CV キャッシュからスコープ画像を取得できない問題で、アクティビティが失敗するケースを修正しました。
* アクティビティ タイムアウト解決時の null 参照エラーを修正しました。
* **Indicate on Screen** の開始やセレクター編集時に発生していた例外を修正しました。
* CV キャッシュが利用できない場合の失敗メッセージを改善しました。

## **v1.1.0**

ビルド日: 2024年4月3日

**追加**

* **CV Type Into** と **CV Table Extract** のターゲットとして、再利用可能なクロップ領域を追加しました。
* **CV Get Text** に背景色フィルタリングを追加しました。
* 設定可能な行閾値と単語区切りを使う、行ベースのテキスト抽出を追加しました。
* 選択インターフェイスに、類似するターゲット要素の可視化を追加しました。

**変更**

* ターゲット解決の前にワークフローを読み込み、編集できるように、記述子の検証を実行時に移動しました。
* 交差比 (IoU) チェックを用いたターゲット順位付けを改善し、類似度のしきい値を更新しました。
* ターゲット ウィンドウが移動したときの切り抜き領域の位置決めと処理を改善しました。
* Selection Options と読み込みウィンドウの体験を改善しました。

**修正**

* OCR テキストそのものがターゲットに選択されていた場合の **CV Get Text** を修正しました。
* クロップ領域が削除されたり、誤った位置にずれたり、サポートされていないコンテキストで選択できてしまう問題を修正しました。
* ビットマップの境界外への画像クロップを防止しました。
* Computer Vision セレクターの複数のターゲット、アンカー、z オーダーの問題を修正しました。
