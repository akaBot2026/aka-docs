# データセキュリティとコンプライアンス

Akabot Centerが顧客のデータをどのように保護しているか、Akabotが製品にセキュリティをどのように組み込んでいるか、また導入環境に適用されるセキュリティ機能と責任については、以下のドキュメントをご覧ください。

- [セキュアな製品開発プロセス](./secure-product-development.md): Akabotが製品をどのように開発、テスト、リリース、サポートしているかを説明します。
- [Akabot Centerセキュリティ概要](./akabot-center-security-overview.md): Akabot Centerがアクセス、認証情報、データをどのように保護しているか、また顧客が担うセキュリティ上の責任を説明します。
- [技術セキュリティおよびデータフローの説明](../../../legal/latest/technical-security-and-data-flow-description.md): アーキテクチャ、データの保存場所、暗号化、ならびにAkabotと顧客との責任分担を説明します。
- [ロール管理](../user-guide/how-to-use-by-function/operation-functions/administration/role-management.md): Akabot Centerにおけるロールと権限を説明します。
- [パスワード ポリシー](../user-guide/how-to-use-by-function/operation-functions/administration/password-policy.md): Akabot Centerにおけるパスワードのルール、多要素認証、アカウントロックアウトを説明します。
